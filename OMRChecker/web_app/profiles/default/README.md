# Default answer sheet

Copied from the project's original `inputs/my_test` profile so a fresh checkout can run the API.

- A4 layout: 60 questions, choices A–D, six-digit Roll.
- The current answer key covers **q1–q15 only, all A, one point each (15 total)**.
- q16–q60 are read but not scored. Update `evaluation.json` for the actual exam.
- The four printed corner markers must match `omr_marker.jpg`.
- Optional `config.json` uses normal OMRChecker tuning settings; web workers always disable GUI/output files.
