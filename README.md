# 📸 OMR Web API

**NOTE**: 
   * OMRChecker มันจะเซฟผลลัพธ์ไว้ที่โฟลเดอร์ `outputs/my_test/results.csv` ใช่ปะ แต่ถ้าระบบมันตรวจเจอไฟล์ `evaluation.json` มันจะเปลี่ยนชื่อไฟล์ตามเวลาเช่น `outputs/Results/Results_03PM.csv` ทำให้ API เว็บเราหาไฟล์ไม่เจอแล้วขึ้น Error
   * **วิธีแก้:** เค้าปรับโค้ด Backend ใหม่ ให้ระบบมัน **"สแกนกวาดหาไฟล์ CSV ล่าสุดอัตโนมัติ"** ไม่ว่าโปรแกรมจะเซฟไปที่โฟลเดอร์ไหน หรือชื่ออะไรก็ดึงมาตรวจได้หมด ไม่มีค้างแน่นอน!
**แก้ระบบค้างเวลาไม่ฝนคำตอบ (JSON Compliance)**:
   * ถ้าเว้นข้อไหนไว้ ไม่ยอมฝน โปรแกรม OMRChecker มันจะส่งค่า `NaN` (ค่าว่าง) ออกมา ซึ่งระบบ JSON ของเว็บมันรับค่านี้ไม่ได้แล้วจะระเบิดเป็น Error 500
   * เลยใส่โค้ดดัก `df.fillna("")` แปลงค่าว่างพวกนี้ให้เป็นตัวอักษรเปล่าๆ แทน ระบบเลยรันต่อได้

## 📂 โครงสร้างโฟลเดอร์ (เผื่อลี่จะเข้าไปดูโค้ด)

```text
OMRChecker/
├── inputs/my_test/           # โฟลเดอร์รับรูป "student_sheet.jpg" ที่ถ่ายส่งมา
├── outputs/                  # โฟลเดอร์เก็บไฟล์ CSV หลังจากระบบตรวจเสร็จ
│   ├── my_test/results.csv   # (สำหรับโหมดปกติ)
│   └── Results/Results_xx.csv # (สำหรับโหมดที่มีไฟล์ evaluation.json = มีเฉลย)
└── web_app/                  # โฟลเดอร์หลักของระบบเว็บที่เราทำเพิ่ม
├── app.py                # ส่วน Backend (FastAPI) คอยสั่งรัน OMR และจัดการไฟล์ CSV
└── templates/
└── index.html        # ส่วน Frontend 

```

## How to Run

### 1. ติดตั้ง Library ก่อน (ถ้ายังไม่ได้ลง)
เปิด Terminal ใน VS Code แล้วพิมพ์คำสั่งนี้เพื่อลงเครื่องมือทำเว็บ:
```bash
pip install fastapi uvicorn pandas jinja2 python-multipart
```

### 2. วิธีรันเซิร์ฟเวอร์
ให้อยู่ที่หน้าโฟลเดอร์โปรเจกต์หลักนะ แล้วพิมพ์คำสั่งตามนี้เลย:

```bash
# 1. เข้าไปที่โฟลเดอร์เว็บของเรา
cd web_app

# 2. สั่งรันเซิร์ฟเวอร์ (แชร์ให้อุปกรณ์อื่นใน Wi-Fi เข้ามาได้)
python3 app.py ->mac
python app.py ->window
```
*ถ้ารันสำเร็จ ใน Terminal มันจะขึ้นว่า `INFO: Uvicorn running on http://0.0.0.0:8000` ถือว่าพร้อมใช้งาน!*

## How to Mobile Testing

1. **ต่อ Wi-Fi เดียวกันก่อน:** เครื่องคอมที่รันโค้ด กับมือถือที่จะใช้สแกน ต้องอยู่บน Wi-Fi เดียวกันนะ (หรือต่อ Hotspotคอม จากโทรศัพท์เอาก็ได้)
2. **หาเลข IP ของคอมพิวเตอร์:** * เปิด Terminal ใน Mac พิมพ์คำสั่ง `ipconfig getifaddr en0` 
   * สมมติว่าได้เลข IP มาเป็น `172.20.10.2`
   * แต่วินโดเค้าไม่รู้วิธีหาอ่ะ
3. **เปิดบนมือถือ:**
   * หยิบมือถือเปิด Safari หรือ Chrome แล้วพิมพ์ URL เป็น: **`http://172.20.10.2:8000`** (เอาเลข IP ที่ได้จากข้อ 2 มาใส่ตามด้วย `:8000`)
   * พอกดปุ่ม **"📷 เปิดกล้องถ่ายรูป"** ก็ถ่ายรูปกระดาษคำตอบได้เลย
   * **ตอนถ่าย:** พยายามถ่ายให้ตรง ขนานกับกระดาษ และให้ติดจุดมาร์กเกอร์สีดำครบทั้ง 4 มุม
